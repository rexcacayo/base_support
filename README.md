# Base Support

> **Versión actual: 1.0.0** (Blender 4.2 – 5.x) → instalar `version_1.0.0/dist/base_support-1.0.0.zip`

Complemento de Blender que **analiza cómo apoya la figura** en la cama y le da un apoyo firme.

Analiza el contacto con la cama, las zonas de apoyo y la estabilidad (centro de gravedad). Hace **base plana** (corte a ras con altura recomendada), **peana** (redonda, ovalada, cuadrada o hexagonal, unida o aparte) o gira la figura a su **mejor apoyo**.

## Familia de plugins

**Mesh Doctor → Print Scale → Thicken → Base Support → BigPrint / MagSnap → Color Print Splitter**
